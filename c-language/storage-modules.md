# C 语言 - 存储期、作用域与模块化专题

## 学习要求

目标是能把一个嵌入式工程拆成职责清晰的 `.c/.h` 模块，并理解变量和函数在何时创建、何时销毁、能被哪些文件访问。

## 应掌握的程度

- 能准确区分块作用域、文件作用域、自动存储期、静态存储期与动态存储期。
- 能正确使用 `static`、`extern`、`const`，避免头文件重复定义和全局变量滥用。
- 能为一个驱动模块设计最小公开接口，隐藏模块内部状态。

## 学习方式与计划

1. 从单文件示例开始，逐步拆为 `driver.c`、`driver.h` 与 `main.c`。
2. 每次拆分都画出符号的可见范围和生命周期。
3. 以 LED 或 UART 驱动为练习，完成接口设计和编译验证。
