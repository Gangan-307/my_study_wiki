# C 语言 - 预处理、编译与链接专题

## 学习要求

目标是理解源码如何变成可烧录固件，并能独立处理宏、头文件、编译告警、链接错误和基础构建问题。

## 应掌握的程度

- 能说明预处理、编译、汇编、链接四个阶段各自的输入和输出。
- 能写安全的条件编译和函数式宏，识别宏的多次求值与优先级问题。
- 能区分编译错误、链接错误和运行时错误，并根据报错定位到模块边界。

## 学习方式与计划

1. 用编译器选项分别查看预处理结果、汇编文件和符号表。
2. 针对每种典型错误，主动构造一个最小复现程序再修复。
3. 在 ESP-IDF 工程中查看一次实际编译命令、组件依赖和最终 ELF 文件。
