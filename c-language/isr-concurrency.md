# C 语言 - 中断、并发与 `volatile` 专题

## 学习要求

中断、DMA、主循环和 RTOS 任务会并发访问数据。学习目标是建立正确的数据共享边界，避免偶现丢数据、死锁和状态错乱。

## 应掌握的程度

- 能说明 `volatile` 的作用与局限：它不等于原子操作，不提供互斥，也不能替代 RTOS 同步原语。
- 能设计“ISR 采集/通知，任务处理”的代码结构，明确 ISR 中能做与不能做的事情。
- 能针对共享变量选择临界区、原子操作、队列、信号量或任务通知，并说明理由。

## 学习方式与计划

1. 先用主循环和模拟 ISR 复现共享计数器丢失更新。
2. 分别用临界区与 RTOS 队列修复，比较适用边界。
3. 以 UART 接收或按键中断为案例，完成 ISR 到任务的数据传递。
