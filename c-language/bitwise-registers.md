# C 语言 - 位运算与寄存器操作专题

## 学习要求

这是驱动开发的核心专题。学习目标是能把数据手册中的寄存器位定义，可靠地转换为可维护的 C 代码，而不是只会记住 `&`、`|`、`^` 的符号含义。

## 应掌握的程度

- 能使用掩码完成单个位和多位字段的读取、置位、清位、翻转与赋值。
- 能写出不会误改其他位的读-改-写代码，并理解并发场景下读-改-写的风险。
- 知道 C 位域的布局由实现决定，默认不用它直接映射硬件寄存器。

## 学习方式与计划

1. 用 8 位二进制数手算每一种位运算的输入和输出。
2. 围绕 GPIO、UART 或定时器的真实寄存器定义练习掩码。
3. 把寄存器操作封装成宏或内联函数，并用调试器观察结果。
