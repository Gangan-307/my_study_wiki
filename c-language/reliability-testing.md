# C 语言 - 嵌入式可靠性与测试专题

## 学习要求

目标是把“代码能跑”提升为“异常输入、长时间运行和资源紧张时仍可定位、可恢复”。本专题结合 C 编码习惯、调试与测试方法学习。

## 应掌握的程度

- 能设计一致的返回码、参数校验、断言、超时与错误恢复路径。
- 能区分适合主机单元测试的纯逻辑与必须上板验证的驱动代码。
- 能用编译告警、GDB、日志、逻辑分析仪或示波器建立故障定位链路。

## 学习方式与计划

1. 每个新模块都先写正常、边界和异常三类测试用例。
2. 以“编译零警告”为最低门槛，记录每次告警的根因。
3. 每周选一个已完成模块，补充超时、错误码和一次故障复盘。
