# C 语言 - 内存布局与未定义行为专题

## 学习要求

嵌入式故障常表现为偶现死机、数据异常或 HardFault。本专题要求从内存布局、对象生命周期和 C 的未定义行为角度定位根因。

## 应掌握的程度

- 能区分栈、堆、`.data`、`.bss`、`.rodata`、代码段的用途和典型问题。
- 能识别并避免越界、野指针、悬空指针、未初始化读取、无效强转和未对齐访问。
- 能从对象的定义方式判断其可能所在内存段，并用 GDB/调试器验证变量实际所在区域。

## 学习方式与计划

1. 用 `sizeof` 与地址观察不同对象的存储位置。
2. 每日构造一个内存错误，用编译器告警、GDB 或 Sanitizer 在主机侧定位。
3. 在 MCU 上复盘一次栈溢出或内存越界的故障路径。

> `.map` 文件的实际分析方法见 [嵌入式内存优化与 `.map` 文件分析](../tools/debugging/memory-opt.md)。
