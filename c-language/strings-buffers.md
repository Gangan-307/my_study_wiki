# C 语言 - 字符串与缓冲区专题

## 学习要求

嵌入式通信大量处理“原始字节”，而不是总以 `\0` 结尾的文本。需要同时掌握 C 字符串规则和带长度的二进制缓冲区处理方式。

## 应掌握的程度

- 能区分字符数组、字符串常量、指向字符串常量的指针和二进制缓冲区。
- 能安全使用 `memcpy`、`memset`、`memcmp`、`strlen` 等函数，明确源、目标和长度边界。
- 能实现 UART 环形缓冲区与基础协议帧解析，避免越界、未终止和数据覆盖。

## 学习方式与计划

1. 先通过内存视图观察字符串末尾的 `\0` 与字节数组的区别。
2. 为每个库函数记录输入限制、返回值、常见误用和替代写法。
3. 用环形缓冲区接收模拟串口数据，处理粘包、半包与缓冲区满。
