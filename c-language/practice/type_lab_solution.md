## 题 1：安全范围转换

### 实现步骤

1. 先检查 `output == NULL`，避免通过空指针写内存。
2. 检查 `input < 0`，因为 `uint8_t` 不能表示负数。
3. 检查 `input > UINT8_MAX`，因为 `uint8_t` 最大只能表示 `255`。
4. 只有全部检查通过后，才执行 `(uint8_t)input` 并写入输出参数。

```c
if ((output == NULL) || (input < 0) || (input > (int32_t)UINT8_MAX)) {
    return false;
}
*output = (uint8_t)input;
```

这样能保证失败时输出值完全不变。若一开始就强转，`300` 会变成 `44`，`-1` 会变成 `255`，错误数据会被悄悄接受。

## 题 2：解析大端传感器帧

输入帧为：

```text
{0x01, 0x2C, 0xFE, 0xD4}
```

### 第一步：检查接口和长度

任何指针为 `NULL` 或长度不是 4 时立即返回。所有输出变量均在校验和解析完成后才写入，因此失败路径不会破坏调用者原有数据。

### 第二步：组合无符号电压值

大端序的第一个字节在高位：

```text
0x01 << 8 | 0x2C = 0x012C = 300
```

代码先把字节转为 `uint16_t`，再移位；否则 `uint8_t` 在表达式中会发生整数提升，表达式含义不够明确。

### 第三步：将补码转换为有符号温度

`0xFED4` 的最高位为 1，表示 16 位补码负数。先得到无符号位模式 `65236`，再减去 `65536`：

```text
65236 - 65536 = -300
```

中间结果使用 `int32_t`，因为它可以安全表示 `-32768` 到 `32767`。最后转换为 `int16_t` 是安全的，因为该范围已经确定。

不能用 `(uint16_t *)frame` 解引用：缓冲区可能未对齐、目标端序可能不同，也可能触发别名规则问题。

## 题 3：计时器回绕

核心代码是：

```c
return (now - start) >= timeout_ms;
```

无符号 32 位减法按 `2^32` 回绕。例如 `start = UINT32_MAX - 9`、`now = 20`：从 `start` 走到最大值后回到 0，再到 20，差值仍为 30。

不应先判断 `now >= start`，因为一旦发生回绕，`now` 会小于 `start`。这个方法要求两次采样之间不能跨越完整的 32 位计时周期。

## 挑战题

### 有符号长度与无符号容量

先检查 `length >= 0`，再将其转换为 `uint16_t` 比较容量：

```c
return (length >= 0) && ((uint16_t)length <= capacity);
```

这样不会让 `-1` 在无符号比较中变成 `65535`。

### ADC 缩放

原函数返回 `uint8_t`，但业务范围是 `0` 到 `1000`，超过 `uint8_t` 的最大值 `255`，所以返回类型必须改为 `uint16_t`。

乘法前将 `raw` 提升到 `uint32_t`：

```c
return (uint16_t)(((uint32_t)raw * 1000U) / 4095U);
```

这样中间乘积按 32 位无符号数计算。实现额外将超过 `4095` 的输入钳制到满量程，避免无效 ADC 原始值输出大于 `1000`。
