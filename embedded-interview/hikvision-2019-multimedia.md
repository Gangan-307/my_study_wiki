## 一、选择题（25 题）

### M-Q01｜已初始化的 static 变量在哪个段 :id=mq01
**题：** 下面的 C 程序在 Linux 下使用 gcc 编译成功后，变量 k 处于（）中。
```c
int j = 100;

int main(int argc, char **argv)
{
	static k = 0;
	int i = 0;
	for (i = 0; i<j; i++) {
		k += i;
	}

	return 0;
}
```
**选项：** A. text 段　B. data 段　C. bss 段　D. 栈
**KEY：** B
**解析：** 原文无解析。【自核】`static` 局部变量不占栈，在静态存储区；带显式初值 → 归入 `.data`（未初始化的静态变量才进 `.bss`）。另注意 `static k = 0;` **缺类型**，只有 C89 的隐式 `int` 才能编译，C99 之后 gcc 默认会报错——**这类"题目本身不严谨"的地方，面试时指出来是加分项**。关联 [C06](/embedded-interview/c-basics.md#c06)、[存储期与模块化](/c-language/storage-modules.md)。

### M-Q02｜关系表达式的值 :id=mq02
**题：** 下列表达式中 a 的值为多少？`int a=(3!=2);`
**选项：** A. 1　B. 0　C. 3　D. 2
**KEY：** A
**解析：** 原文无解析。【自核】C 里关系/逻辑表达式的结果是 `int` 类型的 1 或 0。与 BSP 卷 Q11、2024 卷的"返回类型是整型不是布尔"是同一考点族。

### M-Q03｜数组强转指针后的取值与字节序 :id=mq03
**题：** 下列表达式中 a 的值是多少？
```c
char test[8] = { 0x01,0x02,0x03,0x04,0x05,0x06,0x07,0x08 };
int *test_p = (int *)test;
int a = test_p[1];
```
**选项：** A. 0x08070605　B. 0x04030201　C. 0x05060708　D. 0x01020304
**KEY：** A
**解析：** 原文无解析。【自核】`test_p[1]` 读第 4~7 字节（05 06 07 08）；**小端**下低地址是低位，得 `0x08070605`；大端则是 `0x05060708`。本题按小端出题——所以要先确认字节序。关联 [C10](/embedded-interview/c-basics.md#c10)、[类型与转换](/c-language/types-and-conversions.md)。**注意与 BSP 卷 Q15 是同一道题**：那题问的是**地址**（答 0x1234567C），这题问的是**取到的值**，两个问法都要会。

### M-Q04｜字符数组赋值方式 :id=mq04
**题：** 以下对字符串数组 test 赋值方式错误的是（）。
**选项：** A. `char test[]={'t','e','s','t'};`　B. `char test[10]="test";`　C. `char test[10]; strcpy(test,"test");`　D. `char test[10]; test="test";`
**KEY：** D
**解析：** 原文无解析。【自核】数组名不是可修改左值。同 BSP 卷 [P1-Q20](/embedded-interview/hikvision-written-test.md#p1q20)。

### M-Q05｜通过指针引用数组元素 :id=mq05
**题：** 设有如下语句，下列选项中对数组元素正确的引用是（）。
```c
char a[9] = { 'H','I','K','V','S','I','O','N' };
char *ptr = a;
```
**选项：** A. `*(ptr+5)`　B. `ptr+5`　C. `ptr[a]`　D. `a[ptr]`
**KEY：** A
**解析：** 原文无解析。【自核】A 得第 6 个元素；B 是指针不是元素；C/D 的下标必须是整型，数组名/指针当下标非法。

### M-Q06｜`*(p++) = m++` 的输出 :id=mq06
**题：** 下面程序的输出值，正确的是（）。
```c
int m;
unsigned int a[20];
unsigned int *p;

m = 10;
p = a;
*(p++) = m++;
*p = m;
printf("%d %d\n", a[0], a[1]);
```
**选项：** A. 11 11　B. 10 10　C. 10 11　D. 11 10
**KEY：** C
**解析：** 原文无解析。【自核】`*(p++) = m++` 先用 m 的旧值 10 写入 `a[0]`，然后 p 指向 `a[1]`、m 变 11；再 `*p = m` → `a[1] = 11`。输出 `10 11`。**副作用与求值顺序题**，BSP 卷 Q14 是同类。

### M-Q07｜运算符优先级 :id=mq07
**题：** 下列运算的结果是多少？`int a = 30 + 20 % 3 * 2;`
**选项：** A. 4　B. 42　C. 34　D. 64
**KEY：** C
**解析：** 原文无解析。【自核】`20 % 3 = 2`，`2 * 2 = 4`，`30 + 4 = 34`。见 [运算符专题](/c-language/operators.md)。

### M-Q08｜乘除取模混合 :id=mq08
**题：** 在 C 语言程序中，下列运算后 n 的值是多少？`int n = 0; int f = 17; n = 4 * f % 3 + 1;`
**选项：** A. 9　B. 0　C. 2　D. 3
**KEY：** D
**解析：** `68 % 3 = 2`，`2 + 1 = 3`。与 BSP 卷 [P1-Q16](/embedded-interview/hikvision-written-test.md#p1q16) 完全同题（选项顺序不同）。

### M-Q09｜宏形参未加括号 :id=mq09
**题：** 设有如下宏定义，则执行语句后的输出是（）。
```c
#define f(x) (x*4)
printf("%d\n", 2 * f(5 + 3));
```
**选项：** A. 52　B. 22　C. 34　D. 64
**KEY：** C
**解析：** 原文无解析。【自核】展开为 `2 * (5+3*4)` = `2 * 17` = **34**。即使给整个宏体加了括号，**形参 x 自己没加括号**照样出事。这是宏陷阱的第二层，比 BSP 卷 Q13/Q18 更隐蔽。关联 [C11](/embedded-interview/c-basics.md#c11)。

### M-Q10｜宏参数不加括号 :id=mq10
**题：** 设有如下宏定义，则执行语句后 a 的值是（）。`#define TEST(a,b) a*b` → `int a = TEST(1 + 2, 3);`
**选项：** A. 3　B. 7　C. 2　D. 9
**KEY：** B
**解析：** 展开为 `1 + 2 * 3` = 7。同 BSP 卷 [P1-Q18](/embedded-interview/hikvision-written-test.md#p1q18)。

### M-Q11｜访问效率最高的存储空间 :id=mq11
**题：** 如下哪种存储空间数据访问效率最高（）。
**选项：** A. Flash　B. 片内 RAM　C. 不可 Cache 内存　D. 可 Cache 内存
**KEY：** D
**解析：** 原文无解析。【自核】命中 Cache 的访问最快。**这是海康笔试里少见的体系结构题**（另一道是 Q20），说明存储层次需要基础准备，但不需要深入到映射计算。

### M-Q12｜信号量的错误描述 :id=mq12
**题：** 以下关于信号量描述错误的为（）。
**选项：** A. 信号量只能在线程之间共享　B. 不允许销毁一个正在等待的信号量　C. 用户态使用的信号量分为 POSIX 信号量和 SYSTEM V 信号量　D. 信号量有两种基本操作：V 操作信号量加 1；P 操作信号量减 1（如果信号量为 0，则阻塞）
**KEY：** A
**解析（原文）：** 在 Linux 上，**同一进程的不同线程之间只使用 POSIX 信号量；进程之间可以使用 System V 信号量**。所以"只能在线程之间共享"错误。关联 [R03](/embedded-interview/rtos.md#r03)。

### M-Q13｜不是引起调度切换的直接原因 :id=mq13
**题：** 操作系统在运行过程中，不断地选择新进程运行来实现 CPU 的共享，但其中（）不是引起操作系统选择新进程的直接原因。
**选项：** A. 有新进程进入就绪队列　B. 运行进程的时间片用完　C. 运行进程出错　D. 运行进程要等待某一事件发生
**KEY：** A
**解析：** 原文无解析。【自核】同 BSP 卷 [P1-Q09](/embedded-interview/hikvision-written-test.md#p1q09)（KEY C，选项顺序不同）。**注意**：在**抢占式** Linux 上，有高优先级进程进入就绪队列确实会触发重新调度，此项成立与否取决于按非抢占式模型出题——面试被追问时要能说清这个前提。

### M-Q14｜最常用且最高效的 IPC :id=mq14
**题：** Linux 进程间通信方式中，如下哪一种最常用且最高效？
**选项：** A. FIFO　B. 消息队列　C. 共享内存　D. 管道
**KEY：** C
**解析（原文）：** 为什么共享内存最高效？**消息队列和管道基本都是 4 次拷贝，而共享内存（mmap、shmget）只有两次。**
- 4 次：① 用户空间 buf → 内核；② 内核 → 内存；③ 内存 → 内核；④ 内核 → 用户空间 buf。
- 2 次：① 用户空间 → 内存；② 内存 → 用户空间。

关联 [L01](/embedded-interview/linux-basics.md#l01)、[Linux 系统编程](/embedded-linux/system-programming.md)。**"拷贝次数"是这道题的标准答题抓手，务必记住。**

### M-Q15｜临界区的定义 :id=mq15
**题：** 什么是临界区？
**选项：** A. 程序中访问共享资源的片段　B. 其他都不对　C. 程序结束运行即将退出的地方　D. 程序开始运行的地方
**KEY：** A
**解析：** 原文无解析。【自核】临界区指访问共享资源、需要互斥进入的代码片段。

### M-Q16｜冒泡排序的时间与空间复杂度 :id=mq16
**题：** 冒泡排序时间复杂度和空间复杂度分别是（）。
**选项：** A. 2\*n、2　B. n\*n、2　C. n\*n、1　D. 2\*n、1
**KEY：** C
**解析：** 原文无解析。【自核】两层循环 O(n²)；原地交换只需常数额外空间 O(1)。

### M-Q17｜层序遍历序列里哪个是堆 :id=mq17
**题：** 下列序列都是经过层序遍历完全二叉树的结果，其中是堆的序列是（）。
**选项：** A. 94、21、36、28、57、73　B. 21、28、57、36、94、73　C. 21、36、73、28、57、94　D. 94、57、36、28、73、21
**KEY：** B
**解析：** 原文无解析。【自核】按层序还原完全二叉树后验证小顶堆性质（父 ≤ 子）：B 为 21→(28,57)，28→(36,94)，57→(73)，全部满足。A 的 94 有子 21 破坏；C 的 36 有子 28 破坏；D 不满足大顶堆（57 有子 73）。**方法比答案重要：把层序序列画成树，再逐对比较父与子。**

### M-Q18｜队列与栈的说法（选不正确） :id=mq18
**题：** 以下关于队列和栈的说法不正确的是（）。
**选项：** A. 队列操作中，仅有入队和出队　B. 设计队列和栈，均可以采用数组和链表的方式　C. 可以使用队列模拟栈的操作　D. 函数调用参数环境的保存，应用的是栈的操作

### M-Q19｜可从任意元素定位目标的结构 :id=mq19

### M-Q20｜不属于 Cache 映射方式的是 :id=mq20
**题：** 下面不属于 cache 的映射方式的是（）。
**选项：** A. full-associative（全关联）　B. direct-mapping（直接映射）　C. indirect-mapping（间接映射）　D. set-associative（组相关）

## 二、简答题（2 题）—— 多媒体岗的方向性差异

这两题是本卷**区别于 BSP 卷**的地方，直接对着海康的 DVR/NVR 与音视频业务出题。

### M-S1｜DVR/NVR 录像存储容量估算 :id=ms1
**题（原文）：** 录像存储是 DVR/NVR 产品中一个非常重要的功能，客户对产品的存储能力非常看重。假设存储需求总量 = 通道数 × 录像码率 × 录像时间：已知通道数 = 16，各个通道的录像码率都是 4Mb/s，预期录像时间为一个月（按照 30 天计算），请问客户至少需要多大的硬盘？
**原文解答（照抄）：** `30*24*3600*4*16 = 165888000Mb = 162000Gb`
**【自核】完整算法与单位坑：**
1. 秒数：30 × 24 × 3600 = 2 592 000 s
2. 总量（bit）：2 592 000 × 4 Mb/s × 16 通道 = **165 888 000 Mb**
3. 换算：÷1024 → 162 000 Gb；**再 ÷8 才是字节** → 20 250 GB ≈ **19.8 TB**
4. 原文只做到第 3 步、把 bit 当作硬盘容量表述，**单位混用且没落最终结论**。
**这道题真正的考点**：码率单位 `Mb/s`（兆比特/秒）与硬盘容量 `MB/GB`（字节）之间的 ÷8，以及按 1000 还是 1024 进位。**面试时先说明进位约定，再给结论。**

### M-S2｜音频采样数据量与 I2S SCLK 频率 :id=ms2
**题（原文）：** 假定采用 32k 的采样率对音频进行采样，采样精度为 16bit，双声道。请问每秒的数据量是多少字节？如果将上面采样的数据按照 20ms 作为一帧，则每帧数据量是多少字节？如果采用 I2S 总线传输，请问 I2S 中串行时钟（SCLK）的频率至少应为多少？
**原文解答（照抄）：**
- 1 秒钟的数据量：`32000*16*2 = 1024000 bit = 128000 字节`
- 1 帧的数据量：`128000/(1000/20) = 2560 字节`
- SCLK 频率：`2*32000*16 = 1024000 Hz`
**【自核】复核：** 32 000 × 16 bit × 2 声道 = 1 024 000 bit/s = 128 000 字节/s；每 20 ms 一帧 → 128 000 ÷ 50 = 2 560 字节；I2S 每个 bit 一个 SCLK 周期、两声道在同一条 SCLK 上分时传输 → 1.024 MHz。文字解答自洽。
**说明：** 原文解答后附有一张公式图（`https://i-blog.csdnimg.cn/blog_migrate/0686c081aef38f6517189877e9043494.jpeg`），本环境视觉通道不可用，**图中内容未取得**，不做猜测。
**关联：** [ADC 模数转换](/hardware-drivers/peripherals/adc.md)、[SPI 总线协议](/hardware-drivers/protocols/spi.md)（I2S 与 SPI 同为移位时钟类接口，可对照记忆）。
