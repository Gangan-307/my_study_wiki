# Wi-Fi 配网技术学习纲要

> 当前状态：已建立学习范围，待选择一种主方案和一种兜底方案完成实机验证。

## 应掌握的内容

### 1. 配网方式

- SmartConfig、SoftAP、BLE 配网、二维码和有线配置的原理。
- 各方案对手机权限、兼容性、用户体验和硬件成本的影响。
- 首次配网、重新配网、恢复出厂和更换路由器的流程。

### 2. 状态机设计

- 等待配置、接收凭据、连接验证、保存和失败回退。
- 超时、重试、取消、断电恢复及配网状态指示。
- 手机端与设备端的确认机制，避免“手机显示成功但设备未联网”。

### 3. 安全与量产

- SSID/密码传输保护和本地安全存储。
- 设备身份认证、一次性会话、防重放和日志脱敏。
- 批量生产、售后重置和异常网络兼容性测试。

## 实践清单

- [ ] 完成 BLE 或 SoftAP 配网并持久化凭据。
- [ ] 测试错误密码、隐藏 SSID、弱信号和中途断电。
- [ ] 实现长按按键进入重新配网与恢复出厂。
- [ ] 检查日志中是否泄露 Wi-Fi 密码或敏感信息。

## 完成标准

能够画出完整配网状态机，并保证成功、失败、取消和断电后都有明确且可恢复的行为。
