# Wi-Fi 协议与连接机制学习纲要

> 当前状态：已建立学习范围，待结合抓包、日志和弱网测试完善。

## 应掌握的内容

### 1. 802.11 基础

- Station、AP、BSSID、SSID、信道和频段的含义。
- 主动/被动扫描、认证、关联以及四次握手的连接过程。
- 管理帧、控制帧、数据帧及常见断开原因码。

### 2. 网络接入

- 开放网络、WPA2/WPA3 和个人/企业认证的区别。
- Wi-Fi 链路建立后 DHCP、ARP、DNS 和 IP 通信的关系。
- RSSI、速率、自适应重传、漫游和省电模式。

### 3. 工程调试

- 扫描不到、认证失败、关联失败和获取不到 IP 的分层定位。
- 2.4GHz 干扰、信道拥塞、天线和供电问题。
- 串口日志、路由器状态、抓包和吞吐测试工具。

## 实践清单

- [ ] 记录一次从扫描到获取 IP 的完整日志。
- [ ] 分别制造密码错误、DHCP 失败和信号弱场景。
- [ ] 测量不同距离/信道下的 RSSI、丢包和吞吐量。
- [ ] 分析一次掉线原因码并完成自动恢复。

## 完成标准

能够把“连不上网”拆分到扫描、认证、关联、地址获取和上层网络，并用对应证据定位问题。
