# LVGL 界面开发学习纲要

> 当前状态：已建立学习范围，待结合实际屏幕逐项补充界面、性能和内存数据。

## 应掌握的内容

### 1. 核心模型

- 对象树、父子关系、坐标、布局、样式和状态。
- 事件机制、定时器、动画和页面生命周期。
- 字体、图片、颜色格式和资源转换流程。

### 2. 平台移植

- 显示驱动、输入设备、系统 Tick 和任务调度接口。
- 单缓冲、双缓冲、局部缓冲以及 DMA 刷屏。
- 屏幕方向、触摸校准、缓存一致性和线程约束。

### 3. 工程与性能

- Flex/Grid 布局、组件复用和业务逻辑分层。
- 刷新率、脏矩形、CPU 占用、显存与资源占用。
- 跨线程更新、页面销毁、资源泄漏和卡顿定位。

## 实践清单

- [ ] 移植显示和触摸，完成按钮、列表及状态页面。
- [ ] 使用事件和定时器更新数据，避免阻塞 GUI 线程。
- [ ] 比较不同缓冲方案的帧率、撕裂和内存占用。
- [ ] 完成两个页面切换并验证反复进入后无明显泄漏。

## 完成标准

能够独立完成 LVGL 基础移植和多页面界面，解释刷新链路，并用测量数据定位卡顿、撕裂或内存问题。
