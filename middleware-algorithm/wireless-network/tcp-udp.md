# TCP/UDP 网络套接字学习纲要

> 当前状态：已建立学习范围，待在 WSL 与开发板之间完成实际通信、抓包和异常测试。

## 应掌握的内容

### 1. 网络基础

- IP 地址、子网、端口、DNS、路由和字节序。
- TCP、UDP 的连接模型、可靠性、边界和适用场景。
- 客户端/服务器、长连接、心跳和重连策略。

### 2. Socket 编程

- `socket`、`bind`、`listen`、`accept`、`connect` 的职责。
- `send`/`recv` 的短写、短读、关闭和错误处理。
- 阻塞、非阻塞、超时以及 `select`、`poll`、`epoll`。

### 3. 应用协议与可靠性

- TCP 字节流上的消息边界、长度字段、粘包和半包处理。
- UDP 数据报边界、丢包、乱序、重复及应用层确认。
- 心跳、重连、限流、缓存上限和异常连接清理。

### 4. 调试与安全

- 使用 `ss`、`netstat`、`nc`、Wireshark/tcpdump 定位问题。
- 区分连接拒绝、超时、对端关闭、网络不可达和 DNS 错误。
- 输入长度校验、资源释放和基本 TLS 概念。

## 实践清单

- [ ] 编写 TCP 回显服务器与客户端，处理多个客户端。
- [ ] 实现带长度字段的消息协议和完整收发函数。
- [ ] 编写 UDP 状态上报程序并模拟丢包、重复和乱序。
- [ ] 使用抓包解释一次 TCP 建连、数据传输和关闭过程。

## 完成标准

能够独立写出健壮的客户端/服务器程序，并根据错误码、连接状态和抓包证据定位网络故障。
