# BLE 低功耗设计学习纲要

> 当前状态：已建立学习范围，待结合实际设备的电流测量和连接测试完善。

## 应掌握的内容

### 1. 功耗来源

- 广播、扫描、建立连接、连接事件和数据收发的功耗组成。
- CPU、射频、传感器、屏幕和外设对整机功耗的影响。
- 平均电流、峰值电流、电池容量和实际续航之间的关系。

### 2. BLE 参数

- 广播间隔、扫描窗口和扫描间隔。
- 连接间隔、从机延迟、监督超时及合法参数关系。
- MTU、Data Length、PHY 和单次连接事件数据量。

### 3. 系统策略

- 深睡眠、轻睡眠、唤醒源和状态保存。
- 批量上传、事件驱动、断线重连与后台广播策略。
- 手机兼容性、连接稳定性和低功耗之间的权衡。

## 实践清单

- [ ] 测量未连接广播和已连接空闲状态的平均电流。
- [ ] 对比两组连接参数的功耗、延迟和稳定性。
- [ ] 实现传感器低频采集、批量上传和自动休眠。
- [ ] 记录至少一次异常耗电的定位过程。

## 完成标准

能够用实测数据解释主要耗电来源，并在功耗、响应速度、吞吐量和连接稳定性之间选择参数。
