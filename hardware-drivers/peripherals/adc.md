# ADC 模数转换学习纲要

> 当前状态：已建立学习范围，待通过采样实验补充计算过程、数据和误差分析。

## 应掌握的内容

### 1. 转换原理

- 分辨率、参考电压、量化误差、采样率和有效位数。
- ADC 输入范围、输入阻抗、采样保持时间和前端滤波。
- 单次、连续、扫描和差分采样的适用场景。

### 2. 数据采集

- 通道、时钟、衰减/增益和采样周期配置。
- 轮询、中断和 DMA 三种采集方式。
- 原始码值到电压、温度等工程量的定点或浮点换算。

### 3. 精度与可靠性

- 零点、增益、参考源、噪声和电源纹波带来的误差。
- 平均、中值、限幅及低通滤波的基本使用。
- 校准、过采样以及异常值和断线检测。

## 实践清单

- [ ] 测量稳定直流电压并与万用表结果比较。
- [ ] 使用 DMA 连续采样，统计最小值、最大值、均值和波动。
- [ ] 对同一组数据比较原始值、均值滤波和中值滤波。
- [ ] 记录参考电压变化或不同采样周期对结果的影响。

## 完成标准

能够选择合适的采样参数，正确换算工程量，并通过数据统计区分量化误差、噪声和配置错误。
