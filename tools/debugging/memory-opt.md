# 嵌入式内存优化与 `.map` 文件分析专题

## 学习要求

本专题负责理解链接后的真实内存占用。目标是能通过 `.map`、ELF 和调试信息定位 Flash/RAM 超限、全局数组过大、栈空间不足和代码体积异常。

## 应掌握的程度

- 能区分 Flash 与 RAM 的占用，读懂 `.text`、`.rodata`、`.data`、`.bss`、栈与堆的基本含义。
- 能在 `.map` 文件中定位体积较大的函数、全局变量、静态变量和库对象，并追溯其源码归属。
- 遇到“链接内存不足”或运行期栈溢出时，能提出有依据的优化方案并完成验证。

## 学习方式与计划

1. 先从一个最小工程生成 `.map`，将 C 源码中的全局变量逐项对应到各内存段。
2. 再分析一次 ESP-IDF 构建输出，记录前五个占用最大的符号和所在组件。
3. 最后完成一次优化闭环：测量占用、改动代码、重新构建、对比优化前后数据。
