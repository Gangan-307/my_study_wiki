### Q1｜已初始化的 static 全局/局部变量存放于哪个段
**题干：** 下面的C程序在Linux下使用gcc编译成功后变量k处于（）中。
```cpp
int j = 100;

int main(int argc, char **argv)
{
	static k = 0;
	int i = 0;
	for (i = 0; i<j; i++) {
		k += i;
	}

	return 0;
}
```
**选项：** A. text段 B. data段 C. bss段 D. 栈
**答案：** B
**解析：** 原文无解析。【自核】`static` 局部变量不占栈，存放于静态存储区；因带显式初值 `= 0`，GCC 归入已初始化数据段 `.data`（未初始化的静态变量才进 `.bss`）。另注：`static k = 0;` 缺类型，按 C89 隐式 `int` 才可编译，C99 后已不允许。

### Q2｜关系运算表达式的取值
**题干：** 下列表达式中a的值为多少？
```cpp
int a=(3!=2);
```
**选项：** A. 1 B. 0 C. 3 D. 2
**答案：** A
**解析：** 原文无解析。【自核】C 中关系/逻辑表达式结果为 `int` 的 1 或 0，`3 != 2` 为真，故 `a = 1`。

### Q3｜数组强转指针后的取数与字节序
**题干：** 下列表达式中a的值是多少？
```cpp
char test[8] = { 0x01,0x02,0x03,0x04,0x05,0x06,0x07,0x08 };
int *test_p = (int *)test;
int a = test_p[1];
```
**选项：** A. 0x08070605 B. 0x04030201 C. 0x05060708 D. 0x01020304
**答案：** A
**解析：** 原文无解析。【自核】`test_p[1]` 读第 4~7 字节（0x05,0x06,0x07,0x08）；小端（x86/ARM 默认）下低地址为低位，值为 `0x08070605`。大端机器则为 `0x05060708`，本题按小端出题。

### Q4｜字符数组的合法赋值方式
**题干：** 以下对字符串数组test赋值方式错误的是（）。
**选项：** A. `char test[]={'t','e','s','t'};` B. `char test[10]="test";` C. `char test[10]; strcpy(test,"test");` D. `char test[10]; test="test";`
**答案：** D
**解析：** 原文无解析。【自核】数组名是常量地址，不能作为左值被整体赋值，`test="test";` 非法；A 为字符列表初始化（注意 A 无结尾 `'\0'`，不是合法字符串但作为数组定义合法）。

### Q5｜通过指针引用数组元素
**题干：** 设有如下的语句，下列选项中对数组元素正确的引用是（）。
```cpp
char a[9] = { 'H','I','K','V','S','I','O','N' };
char *ptr = a;
```
**选项：** A. `*(ptr+5)` B. `ptr+5` C. `ptr[a]` D. `a[ptr]`
**答案：** A
**解析：** 原文无解析。【自核】`*(ptr+5)` 得第 6 个元素 `'I'`；`ptr+5` 是指针不是元素；`ptr[a]`、`a[ptr]` 的下标必须为整型，数组名/指针作下标非法。

### Q6｜`*(p++) = m++` 的副作用与输出
**题干：** 下面程序的输出值，正确的是（）。
```cpp
#include <stdio.h>
#include <stdlib.h>

int main()
{
	int m;
	unsigned int a[20];
	unsigned int *p;

	m = 10;
	p = a;
	*(p++) = m++;
	*p = m;
	printf("%d %d\n", a[0], a[1]);

	return 0;
}
```
**选项：** A. 11 11 B. 10 10 C. 10 11 D. 11 10
**答案：** C
**解析：** 原文无解析。【自核】`*(p++) = m++`：先把 `m` 的旧值 10 写入 `a[0]`，随后 `p` 指向 `a[1]`、`m` 变为 11；再执行 `*p = m` 使 `a[1] = 11`。故输出 `10 11`。

### Q9｜宏替换不带求值（不加括号导致的优先级问题）

### Q11｜存储层次中访问效率最高的空间
**题干：** 如下哪种存储空间数据访问效率最高（）。
**选项：** A. Flash B. 片内RAM C. 不可Cache内存 D. 可Cache内存
**答案：** D

### Q12｜信号量的描述错误项
**题干：** 以下关于信号量描述错误的为（）。
**选项：** A. 信号量只能在线程之间共享 B. 不允许销毁一个正在等待的信号量 C. 用户态使用的信号量分为POSIX信号量和SYSTEM V信号量 D. 信号量有两种基本操作：V操作，信号量加1；P操作，信号量减1（如果信号量为0，则阻塞）
**答案：** A
**解析：** 原文有解答（照抄）：「**在 Linux 上，在相同进程的不同线程之间，则只使用 POSIX 信号量；在进程之间，可以使用 System V 信号量。**」即 A 错在「只能在线程之间共享」，信号量同样可用于进程之间。

### Q13｜不是引起操作系统选择新进程的直接原因
**题干：** 操作系统在运行过程中，不断地选择新进程运行来实现CPU的共享，但其中（）不是引起操作系统选择新进程的直接原因。
**选项：** A. 有新进程进入就绪队列 B. 运行进程的时间片用完 C. 运行进程出错 D. 运行进程要等待某一事件发生
**答案：** A
**解析：** 原文无解析。【自核】时间片用完、运行进程出错、主动阻塞等待事件都会直接导致当前进程让出 CPU 并触发调度；单纯「有新进程进入就绪队列」在非抢占式调度下不直接引起切换（抢占式下会触发，此项存疑，见文末可疑点清单）。

### Q14｜最常用且最高效的 Linux IPC 方式
**题干：** Linux进程间通信方试中，如下哪一种最常用且最高效？
**选项：** A. FIFO B. 消息队列 C. 共享内存 D. 管道
**答案：** C
**解析：** 原文有解答（照抄，「方试」为原文错别字）：「为什么共享内存最高效？**消息队列和管道基本上都是4次拷贝，而共享内存（mmap, shmget）只有两次。** - **4次：1，由用户空间的buf中将数据拷贝到内核中。2，内核将数据拷贝到内存中。3，内存到内核。4，内核到用户空间的buf；** - **2次： 1，用户空间到内存。 2，内存到用户空间。**」

### Q17｜层序遍历序列中哪个是堆
**题干：** 层序遍历的基本思路是：从二叉树的根节点开始，层数依次从1到n层，每层都从左儿子到右儿子遍历，依次按照层顺序遍历。下列序列都是经过层序遍历完全二叉树的结果，其中是堆的序列是（）。
**选项：** A. 94、21、36、28、57、73 B. 21、28、57、36、94、73 C. 21、36、73、28、57、94 D. 94、57、36、28、73、21
**答案：** B
**解析：** 原文无解析。【自核】按层序还原完全二叉树后逐个验证小顶堆性质（父 ≤ 子）：B 为 21→(28,57)，28→(36,94)，57→(73)，全部满足；A 的 94 有子 21 破坏小顶堆，C 的 36 有子 28 破坏，D 的 57 有子 73 破坏大顶堆。

### Q26｜DVR/NVR 录像存储容量估算
**题干：** 录像存储是DVR/NVR产品中一个非常重要的功能，客户对产品的存储能力非常看重。假设存储需求总量=通道数\*录像码率\*录像时间：已知通道数=16，各个通道的录像码率都是4Mb/s，预期录像时间为一个月（按照30天计算），请问客户至少需要多大的硬盘？
**答案：** 原文解答（照抄）：「30\*24\*3600\*4\*16=165888000Mb=162000Gb」
**解析：** 原文仅有该算式、无进一步文字解析。【自核】30×24×3600 = 2 592 000 秒，×4 Mb/s ×16 通道 = 165 888 000 Mb，÷1024 = 162 000 Gb；再 ÷8 换字节 = 20 250 GB ≈ 19.8 TB（按 1024 进位）。原文把 bit 量 `Mb/Gb` 直接当作硬盘容量表述且未做 ÷8 的位→字节换算，单位使用不严谨（见文末可疑点清单）。

### Q27｜音频采样数据量与 I2S SCLK 频率
**题干：** 假定我们采用32k的采样率，对音频进行采样，采样精度为16bit，双声道。请问每秒的数据量是多少字节？如果将上面采样的数据，按照20ms作为一帧，则每帧数据量是多少字节？如果采用I2S总线传输，请问I2S中串行时钟（SCLK）的频率至少应为多少？
**答案：** 原文解答（照抄）：「1秒钟的数据量：32000\*16\*2=1024000bit=128000字节；1帧的数据量：128000/(1000/20)=2560字节；SCLK频率：2\*32000\*16=1024000Hz」
**解析：** 原文另有 1 张图片紧跟本解答之后（https://i-blog.csdnimg.cn/blog_migrate/0686c081aef38f6517189877e9043494.jpeg ），应为该题的公式/计算图。**该图无法转录**：本环境视觉通道（modlens / 图像输入）不可用，直连下载亦被网络层拒绝，故只保留链接、不猜测其内容。【原文为公式图，内容未取得】。【自核】文字解答本身可复核：32000×16×2 = 1 024 000 bit/s = 128 000 字节/s；每 20ms 一帧 → 128000 ÷ 50 = 2560 字节；I2S 串行时钟每 bit 一个周期、两声道共用一条 SCLK 线 → 32000 × 16 × 2 = 1.024 MHz（与原文 `2*32000*16` 同值）。
