# 嵌入式 Linux 两个月学习路线

> 本页是嵌入式 Linux 专项的知识顺序与实验清单；[嵌入式学习总计划](../study-plan.md)负责将 Linux 与 C、MCU、RTOS、网络、项目和求职任务统一排入实际日程。执行时以总计划的周次为准，以本页作为 Linux 专题的验收依据。

## 一、时间与目标边界

当前处于实习期，晚饭后约 20:00 才能开始学习，并且是大小周。建议按每周 **9～12 小时**安排：

- 工作日选 4 晚，每晚 1.5 小时；另一晚用于休息或补欠账。
- 上班的周六只做 30～60 分钟复盘，不安排首次接触的新难点。
- 休息日安排两个 2～3 小时的完整实验块。
- 每周至少留出一次上板时间，不能连续两周只看视频或文档。

两个月约能获得 80～100 小时有效学习时间。核心目标是“打通链路并形成项目”，不是读完厚书或精通内核。

## 二、每天的固定节奏

| 时间 | 内容 | 输出 |
| :--- | :--- | :--- |
| 20:30～20:45 | 回忆上次内容、明确今晚唯一目标 | 一句话目标 |
| 20:45～21:25 | 阅读文档或课程，验证关键命令 | 3～5 条自己的笔记 |
| 21:25～22:10 | 写代码、编译、上板、制造一个错误 | 可运行结果或错误证据 |
| 22:10～22:20 | 总结与提交 | 结论、待解决项、Git commit |

时间不足时宁可完成一个小闭环，也不要同时打开多个专题。

## 三、8 周安排

### 第 1 周：Linux 操作基础

**学习内容**

- 文件系统、路径、权限、用户和软硬链接。
- 进程、信号、前后台任务、`/proc`、日志。
- 管道、重定向、环境变量和简单 Bash 脚本。

**必须完成**

- [ ] 在 WSL 编写系统信息采集脚本，输出 CPU、内存、磁盘、网络和 Top 进程。
- [ ] 能用 `ps`、`top`、`kill`、`dmesg`、`ip`、`ss` 排查一个模拟问题。
- [ ] 不看资料解释 `sudo`、`chmod 755`、管道和重定向的含义。

对应笔记：[Linux 使用基础](linux-foundations.md)

### 第 2 周：开发工具与板卡首次启动

**学习内容**

- Git、GCC、Make、GDB 的基本工作流。
- 串口终端、SSH/SCP、板卡网络和系统信息采集。
- 泰山派的 SoC、内存、eMMC、TF 卡、接口和官方资料归档。

**必须完成**

- [ ] 保存一份完整启动日志和板卡基线信息。
- [ ] 从 WSL 通过 SSH 登录板卡，并使用 SCP 双向传文件。
- [ ] 在板端原生编译并运行一个多文件 C 程序。

对应笔记：[泰山派上板实战](taishan-pi.md)

### 第 3 周：交叉编译与 ELF

**学习内容**

- host、build、target 和 ARM64 ABI。
- 预处理、编译、汇编、链接；静态库与动态库。
- Makefile、CMake、ELF、sysroot 和动态加载器。

**必须完成**

- [ ] 在 WSL 交叉编译程序并在板端运行。
- [ ] 使用 `file`、`readelf`、`nm`、`objdump`、`size` 分析产物。
- [ ] 主动制造一次架构不匹配或动态库缺失，并写出定位过程。

对应笔记：[交叉编译、构建与 ELF](cross-compilation.md)

### 第 4 周：Linux 系统编程

**学习内容**

- 文件描述符、阻塞/非阻塞 I/O、错误处理。
- 进程、信号、线程、互斥锁、条件变量和 IPC。
- TCP/UDP Socket 与 `select`/`poll`/`epoll`。

**必须完成**

- [ ] 写一个健壮的文件复制程序，正确处理短读写和错误码。
- [ ] 写一个线程安全的生产者/消费者程序。
- [ ] 写一个可以同时处理多个连接的 TCP 服务端。

对应笔记：[Linux 系统编程](system-programming.md)

### 第 5 周：启动链、内核与设备树

**学习内容**

- BootROM、SPL/TPL、U-Boot、Kernel、DTB、RootFS 的职责。
- 内核配置与编译产物，模块加载过程。
- DTS/DTSI、节点、属性、compatible、pinctrl 和 status。

**必须完成**

- [ ] 对照串口日志标出启动链各阶段。
- [ ] 找到当前运行内核、DTB、根文件系统和启动参数的信息来源。
- [ ] 反编译当前 DTB，定位一个实际外设节点并解释关键属性。

对应笔记：[启动链与系统组成](boot-chain.md)、[内核、设备树与模块](kernel-device-tree.md)

### 第 6 周：外设访问与入门驱动

**学习内容**

- `libgpiod`、`i2c-dev`、`spidev` 用户态接口。
- 模块生命周期、字符设备、`file_operations`。
- platform device/driver、设备树匹配和并发边界。

**必须完成**

- [ ] 用用户态接口完成一个 GPIO 或 I2C 外设实验。
- [ ] 编译、加载、查看日志并卸载一个 hello module。
- [ ] 完成一个虚拟字符设备，支持基本读写并记录调用路径。

对应笔记：[Linux 驱动开发](driver-development.md)

### 第 7 周：Buildroot 与系统定制

**学习内容**

- 工具链、Bootloader、Kernel、RootFS 的集成关系。
- defconfig、rootfs overlay、自定义 package 和启动服务。
- 可复现构建与版本记录。

**必须完成**

- [ ] 使用与板卡匹配的配置成功完成一次构建。
- [ ] 将自己的应用加入根文件系统，而不是开机后手工复制。
- [ ] 让应用随系统启动，并能查看日志、停止和重启。

对应笔记：[Buildroot 与根文件系统](buildroot.md)

### 第 8 周：综合项目与面试整理

**学习内容**

- 把 ESP32 经验接入 Linux 网关项目。
- 异常恢复、日志、配置、部署、资源统计和测试。
- 用 STAR 和“现象—证据—根因—修复”组织表达。

**必须完成**

- [ ] 项目能连续运行，断网或 ESP32 重启后可以恢复。
- [ ] 仓库包含 README、架构图、构建步骤、测试记录和问题复盘。
- [ ] 录制 2～3 分钟演示，整理一页项目介绍和 10 个追问答案。

对应笔记：[综合项目](project.md)、[复盘与面试清单](review-checklist.md)

## 四、优先级控制

### 前两个月必须掌握

- Shell 基础、Git、GCC/Make、GDB、交叉编译。
- POSIX 文件 I/O、进程线程、同步、Socket。
- 启动链、设备树基础、模块和字符设备基本流程。
- 串口、SSH、日志、`strace` 等问题定位工具。

### 只需建立概念

- U-Boot 命令和环境变量的作用。
- 内核配置系统、驱动模型、Buildroot package 结构。
- 中断、DMA、内存映射在 Linux 下的基本约束。

### 暂缓深入

- Yocto 配方体系、Android Framework、复杂显示和摄像头链路。
- USB、PCIe、网络驱动等复杂子系统。
- 内核调度器、内存管理源码级分析和从零移植整块开发板。

## 五、每周验收

周末只问五个问题：

1. 本周有没有一个不依赖教程也能重新完成的实验？
2. 有没有保存真实命令、代码、日志和环境版本？
3. 有没有主动制造并定位至少一个错误？
4. 能否在 3 分钟内向别人讲清本周最重要的机制？
5. 下周第一晚的唯一任务是什么？

若前三项有两项为“否”，下一周先补实验，不继续追新内容。
